# RASID QGIS Plugin

A QGIS plugin for cloud-based geospatial analysis and satellite processing workflows.

## About

Run remote sensing and geospatial analysis directly in QGIS without local computation. Access satellite imagery from Sentinel-1, Sentinel-2, Mapbox, and Planet, or use your own data.

## Installation

1. Download the plugin ZIP file
2. In QGIS: **Plugins → Manage and Install Plugins → Install from ZIP**
3. Select the ZIP file and install

## Requirements

- QGIS 3.0 or higher
- Internet connection

## Usage

1. Click the Rasid icon in the toolbar
2. Login with your credentials
3. Create a project and select a solution
4. Run processes on your area of interest
